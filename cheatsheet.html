첨부 문제집 176문항과 정답·해설을 바탕으로, CBT에서 다시 풀 문제를 개념별로 연결했다. Ⅰ·Ⅱ는 과목, 뒤 숫자는 교재 문항 번호다. 기출 대비 유형은 공개 출제 영역을 바탕으로 만든 연습이며, 실제 회차의 원문과 출제 빈도는 확인 범위에 포함되지 않는다.

첫 회독은 NULL → 외부 조인 → 집계·윈도우 → 트랜잭션 → 정규화 순서로 진행한다. 정답 번호를 보기 전에 각 문제에서 남는 행, 값, 취소 범위 중 무엇을 묻는지 적어 본다.

결과표를 손으로 그리는 세 가지 유형

NULL과 집계 · 값이 10, NULL, 20이면 COUNT(*)=3, COUNT(x)=2, SUM(x)=30, AVG(x)=15. AVG(COALESCE(x,0))는 10이다. 입력 행이 0건인 전체 집계에서 COUNT는 0, SUM은 NULL이다.

LEFT JOIN · 고객 A는 구매 2건, B는 0건. 고객별 LEFT JOIN 뒤 COUNT(*)는 A 2, B 1이고, COUNT(구매.PK)는 A 2, B 0이다. B의 NULL 확장행을 그려 두면 구분이 쉽다.

윈도우와 GROUP BY · 매출 세 행을 GROUP BY 부서로 집계하면 부서당 한 행. SUM(매출) OVER(PARTITION BY 부서)는 세 행을 유지하고 각 행에 부서 합계를 표시한다. 누적합을 행 단위로 계산하려면 ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW와 안정적인 정렬 기준을 확인한다.

트랜잭션 · Ⅱ-26, 101~103, 119~124

문제의 단서 판단
원자성·일관성·고립성·지속성 전부 성공 또는 취소 / 제약과 정합성 유지 / 동시 실행의 간섭 제어 / 확정 결과 보존
SQL Server, 같은 세션의 중첩 BEGIN @@TRANCOUNT가 1 → 2. 안쪽 COMMIT은 2 → 1, 바깥 COMMIT으로 0이 될 때 확정
저장점 없는 ROLLBACK SQL Server에서 열린 트랜잭션 전체를 취소하고 중첩 횟수를 0으로 초기화
저장점 지정 Oracle SAVEPOINT s → ROLLBACK TO s. SQL Server SAVE TRANSACTION s → ROLLBACK TRANSACTION s. 저장점 뒤 변경만 취소
DDL이 사이에 등장 Oracle은 유효한 DDL 실행 전에 암묵적 커밋, 성공하면 실행 후에도 커밋. SQL Server에서는 일반적인 테이블 DDL을 명시적 트랜잭션에서 롤백할 수 있는 경우가 있으므로 DBMS를 확인

Ⅱ-123의 작업 범위

확정 범위    INSERT 005 → COMMIT                005 유지
취소 범위    BEGIN → DELETE 002 → BEGIN → UPDATE → ROLLBACK
횟수           1                   2                    0
결과         단가 2000인 품목은 002·004·005 → 3건

②를 골랐다면 두 번째 BEGIN을 저장점처럼 읽었는지 확인한다. DELETE를 유지하고 UPDATE만 되돌리려면 DELETE 뒤에 저장점을 만든 후 그 저장점을 지정해 롤백해야 한다.

기출 대비 자가진단 10문제

  1. 주문상세의 PK가 (주문번호, 상품번호)이고 상품번호만 알면 상품명을 알 수 있다. 어떤 정규형을 위반하는가?
  2. x가 3, NULL, 6일 때 COUNT(x), SUM(x), AVG(x)는?
  3. 구매가 없는 고객도 남기되 올해 구매만 연결하려면 구매일 조건을 LEFT JOIN의 ON과 WHERE 중 어디에 둘까?
  4. WHERE x NOT IN (1, NULL)에서 x가 2인 행은 남는가?
  5. ROLLUP(지역, 월)에서 월별 전체 지역 소계가 생기는가?
  6. 점수가 90, 90, 80일 때 80점의 RANK와 DENSE_RANK는?
  7. A에 (1), (1), (2), B에 (1), (3)이 있을 때 UNION과 UNION ALL의 결과 건수는?
  8. SQL Server에서 BEGIN → DELETE → BEGIN → UPDATE → COMMIT → ROLLBACK을 실행하면 DELETE는 남는가?
  9. 월별 매출의 월 값 1·2·3을 각각 결과 열로 바꾸려면 어떤 연산을 쓰는가?
  10. 정규식 ^[0-9]+$에 123, 12A, 빈 문자열 중 무엇이 일치하는가?
정답과 판단 근거
  1. 2NF. 상품명이 복합키의 일부인 상품번호에만 종속된다.
  2. 2, 9, 4.5. NULL을 분모에 포함하지 않는다.
  3. ON. 매칭할 구매만 제한하고 미매칭 고객은 유지한다.
  4. 남지 않는다. 2 <> NULL이 UNKNOWN이므로 전체 조건이 TRUE가 되지 않는다.
  5. 생기지 않는다. (지역, 월), (지역), ()만 생성한다.
  6. 3, 2. RANK는 동점 뒤 순위를 건너뛴다.
  7. 3건, 5건. UNION만 출력 행의 중복을 제거한다.
  8. 남지 않는다. 안쪽 COMMIT 이후에도 중첩 횟수가 1이므로 마지막 ROLLBACK이 둘 다 취소한다.
  9. PIVOT. 월 범주를 열로 바꾸고 매출을 집계한다.
  10. 123만 일치. 시작부터 끝까지 숫자가 한 자 이상 있어야 한다.
